# Leads Finder

Uma ideia de ferramenta para organizar pesquisas e acompanhar contatos comerciais.

O escopo ainda está sendo definido e não há uma aplicação pronta neste repositório. Antes de começar, precisamos decidir quais dados serão úteis, de onde virão e como serão armazenados. A ferramenta não deve coletar informações além do necessário nem contrariar os termos dos serviços consultados.
