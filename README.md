## Ideia do projeto

O objetivo é reunir informações úteis para a prospecção em um fluxo simples, com espaço para registrar o andamento de cada contato. Antes de desenvolver, preciso definir quais dados serão realmente necessários e de quais fontes poderão ser obtidos.

Privacidade e uso responsável fazem parte do escopo: não armazenar informações desnecessárias nem coletar dados em desacordo com os termos dos serviços consultados.

## Estado atual

Este repositório ainda não contém o código da aplicação. Next.js e TypeScript são a stack prevista para o primeiro protótipo; os badges não significam que esses recursos já estejam implementados.

## Escopo inicial

Antes de implementar, vou definir quais campos realmente ajudam a acompanhar uma prospecção e como cada informação será obtida. A primeira versão deve ser pequena e deixar claro o que é anotado manualmente e o que vem de uma fonte externa.
