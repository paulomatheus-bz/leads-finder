# Leads Finder

Projeto de uma ferramenta para apoiar a organização da prospecção comercial.

## Ideia

Reunir informações de potenciais clientes em um fluxo simples de pesquisa e acompanhamento. O escopo ainda está sendo definido e não representa uma ferramenta pronta para uso comercial.

## Situação do repositório

Neste momento há documentação e planejamento, mas não uma implementação versionada. Por isso, o GitHub ainda não apresenta linguagens para este projeto.
