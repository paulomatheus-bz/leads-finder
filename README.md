# Leads Finder

Projeto de uma ferramenta para apoiar a organização da prospecção comercial.

## Objetivo

Reunir informações de potenciais clientes em um fluxo simples de pesquisa e acompanhamento. O escopo ainda está em definição; este repositório não representa uma ferramenta pronta para uso comercial.

## Situação

Há planejamento, mas ainda não existe uma implementação versionada. O GitHub não identifica linguagens de programação para o projeto.

## Decisões antes de implementar

- Definir quais informações serão registradas e por quanto tempo.
- Escolher a origem dos dados e respeitar os termos de uso de cada serviço.
- Planejar busca, acompanhamento e exportação sem coletar dados desnecessários.
